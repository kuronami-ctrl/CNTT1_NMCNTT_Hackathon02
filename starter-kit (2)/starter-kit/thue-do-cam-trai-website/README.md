# CampGo - cho thuê đồ cắm trại
wedsite **cho thuê** *đồ cắm trại*.
## Danh sách thư mục
|Thư mục|Nội dung|
|-|-|
|docs|tài liệu bàn giao|
|data|bảng tính đơn thuê|
|logs|logs truy cập wedsite|

## Lệnh liệt kê dự án

```powershell
Get-ChildItem -Force -Recurse
```
